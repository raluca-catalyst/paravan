### Task 2: Pattern detectors

**Files:** Create `src/detect/patterns.js`. Test `tests/patterns.test.js`.

**Interfaces:**
- Consumes: `fold` (Task 1).
- Produces: type `Span = { start: number, end: number, category: string, text: string, base?: string, genitive?: boolean }` (end exclusive). `detectPatterns(text: string): Span[]` for CNP, TELEFON, EMAIL, IBAN, CARD, ACT_IDENTITATE, DATA_NASTERII, ADRESA, NR_AUTO, IP, FIRMA. May return overlapping spans; Task 4 resolves overlaps.

Rules (pinned):
- CNP: 13 digits, first digit 1-8, valid control digit (weights `279146358279`, remainder 10 → 1).
- TELEFON: RO mobile `(+40|0040|0)7xx` with optional space/dot/dash groups; RO landline `(+40|0)[23]x…` 10 digits; international `+` 1-3 digit prefix then 7-12 digits with separators.
- IBAN: country letters + 2 digits + 11-30 alphanumerics, spaces allowed every 4, valid mod 97.
- CARD: 13-19 digits (spaces/dashes allowed) passing Luhn, not a valid CNP.
- ACT_IDENTITATE: two uppercase letters + 6 digits within 20 chars after `seria|serie|CI|C.I.|buletin|carte de identitate`; 9 digits after `pașaport`.
- DATA_NASTERII: a date (`dd.mm.yyyy`, `dd/mm/yyyy`, `dd-mm-yyyy`, `d <lună> yyyy`) within 25 chars after `născut|născută|data nașterii|n.`.
- ADRESA: from `str.|strada|bd.|bulevardul|calea|șos.|șoseaua|aleea|piața|intrarea` through the following tokens until end of line or `.`/`;` not part of an abbreviation, including `nr.`, `bl.`, `sc.`, `et.`, `ap.` parts; also a standalone run starting with `nr. <num>` followed by `bl.`/`ap.`.
- NR_AUTO: `B` + 2-3 digits + 3 letters, or a valid county code (AB AG AR BC BH BN BR BT BV BZ CJ CL CS CT CV DB DJ GJ GL GR HD HR IF IL IS MH MM MS NT OT PH SB SJ SM SV TL TM TR VL VN VS) + 2 digits + 3 letters, optional spaces. Case-sensitive.
- IP: IPv4 with octets 0-255; IPv6 with at least 3 colon groups.
- FIRMA (case-sensitive): 1-5 capitalized tokens followed by `SRL|S.R.L.|SRL-D|SA|S.A.|PFA|II|I.I.|Grup|Group`.

### Task 3: Names and places

**Files:** Create `src/detect/tokens.js`, `src/detect/names.js`, `src/detect/places.js`. Test `tests/names.test.js`.

**Interfaces:**
- Consumes: Task 1 sets, `fold`, `Span`.
- Produces: `tokenize(text: string): {text: string, start: number, end: number, sentenceStart: boolean, capitalized: boolean}[]` (word = Unicode letters plus inner hyphen/apostrophe, e.g. `Ana-Maria`; `sentenceStart` true when preceded, ignoring spaces/quotes/bullets/list numbers, by segment start, newline, `.`, `!`, `?`, `…`, or `:`). `detectNames(text: string): Span[]` (category `PERSOANA`; `base` = nominative form; `genitive: true` for derived genitives). `detectPlaces(text: string): Span[]` (category `LOCALITATE`).

Name rules, in order:
1. **Speaker labels:** at line start, 1-3 capitalized words then `:`. If the label (folded) is in `ROLE_LABELS`, leave it. Otherwise the label words form one `PERSOANA` span.
2. **Listed name:** capitalized token whose fold is in first names, surnames or diminutives. If the token is also in `COMMON_WORDS` (only possible via diminutives or after Task 1 filtering edge cases) or is one of the known common-word surnames (`floare, lupu, negru, bucur, albu, rus, pop, lungu, munteanu`… any surname whose fold appears in the raw frequency list), mask only when mid-sentence, or at sentence start when the next token is a listed name.
3. **All caps:** a token in all caps longer than 2 letters is checked by its fold like rule 2 (catches `MARIA POPESCU`). Tokens of 2-5 uppercase letters not in name lists are left (acronyms).
4. **Genitive-dative:** if not listed, derive: `-iei`→`-ia`, `-ei`→`-a`, `-căi`→`-ca`, `-găi`→`-ga`; if the derived fold is a female first name → span with `base` = derived form (original casing), `genitive: true`. Exact list match always wins over derivation.
5. **Hints:** `dl.|dna.|d-l|d-na|domnul|doamna|dr.` followed by 1-3 capitalized tokens → those tokens are one span even if unlisted.
6. **Fallback (Raluca's decision):** a capitalized token not in `ALLOWLIST` and not in `ROLE_LABELS`: mid-sentence and fold not in `COMMON_WORDS` → span; sentence start and fold not in `COMMON_WORDS` → span. A hyphenated token whose first part is a common word and whose other parts are clitics (`i, l, o, le, mi, ți, ne, vă, și, s, n, au, a, ai, am, ați`) counts as a common word (`Scrie-i`, `Spune-mi`).
7. **Joining:** adjacent name spans separated only by a space or hyphen merge into one span (`Maria Popescu`, `Ana-Maria Ionescu`).

Place rule: longest match of `LOCALITIES` (case-sensitive on the first letter, diacritic-insensitive) on token boundaries. A single-word locality whose fold is in `COMMON_WORDS` matches only mid-sentence.

### Task 4: detect, pseudonymize, restore

**Files:** Create `src/detect/index.js`, `src/core/tags.js`, `src/core/pseudonymize.js`, `src/core/restore.js`. Test `tests/core.test.js`.

**Interfaces:**
- Consumes: `detectPatterns`, `detectNames`, `detectPlaces`, `Span`, `fold`.
- Produces:
  - `detect(text: string, manual?: {value: string, category: string}[]): Span[]` — sorted, non-overlapping. Overlap: longer span wins; equal length by priority `CNP > CARD > IBAN > EMAIL > TELEFON > IP > ACT_IDENTITATE > NR_AUTO > DATA_NASTERII > ADRESA > FIRMA > PERSOANA > LOCALITATE`. Manual values match case- and diacritic-insensitively on word boundaries and beat everything.
  - type `Key = { version: 1, source: string, created: string /* ISO */, entities: { tag: string, category: string, value: string, forms: string[] }[] }`
  - `pseudonymize(segments: string[], opts?: { manual?: {value: string, category: string}[], source?: string }) => { segments: string[], key: Key, counts: Record<string, number>, alreadyTagged: boolean }`
  - `restore(segments: string[], key: Key) => { segments: string[], replaced: number, unknownTags: string[] }`
  - `findTags(text: string): {match: string, category: string, n: number, index: number}[]` in `tags.js`, tolerant forms: optional `\` before brackets, case-insensitive category, `_` or space or `\_` between category and number, brackets optional only when category is one of the 13 and followed by `_digits`.

Entity rules (pinned):
- Entities are shared across all segments of one document.
- Non-name entity key = digits only (CNP, TELEFON, IBAN, CARD), lowercase (EMAIL), fold otherwise. `value` = first surface seen.
- PERSOANA: full names (2+ words) are entities by fold. A single-word mention (or genitive `base`) joins a full-name entity when exactly one full name contains that word; with zero matches it is its own entity; with two or more matches it gets its own separate entity (privacy wins, spec §13). `value` = most frequent nominative surface form of that entity, ties → longest.
- A genitive span is written as `lui [TAG]`; if the text right before the span already ends with `lui `, write just `[TAG]`.
- Numbering per category by first appearance. If the input already contains tags (`findTags`), set `alreadyTagged: true` and start each category's numbering after the highest existing N.
